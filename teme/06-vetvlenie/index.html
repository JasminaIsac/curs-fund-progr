    Основы программирования · тема 06

    Операторы отношения, логика и ветвление

    Программа выбирает путь: сравнения, логические связки, if/else и switch — с подробными примерами на C.

    0 разделов 0 примеров C 0 вопросов
    1. Чем && отличается от ||?
    И требует оба истинных; ИЛИ — хотя бы один.
    2. Почему опасен if (x = 1)?
    Это присваивание, не сравнение; условие обычно становится истинным.
    3. Зачем break в switch?
    Чтобы не выполнять следующие case.
    4. Когда switch удобнее длинной цепочки if?
    Когда ветвление идёт по одному дискретному значению среди констант.
