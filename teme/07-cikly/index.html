    Операторы цикла

    Цикл повторяет действия. Подробно разберём while, do-while, for и типовые шаблоны задач на C.

    0 разделов 0 примеров C 0 вопросов
    1. Чем while отличается от do-while?
    do-while выполнит тело хотя бы один раз.
    2. Что обязательно менять в while?
    Переменную, от которой зависит условие — иначе бесконечный цикл.
    3. Когда for удобнее while?
    Когда есть явный счётчик и известны границы.
    4. Сколько раз внешний цикл при rows=3, cols=5 печатает перевод строки?
    3 раза (по числу строк).
