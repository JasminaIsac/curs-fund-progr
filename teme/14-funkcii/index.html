    Использование функций

    Функции структурируют программу. Разберём синтаксис, виды функций и типичные ошибки на C.

    0 разделов 0 примеров C 0 вопросов
    1. Что делает return в int-функции?
    Завершает функцию и передаёт значение вызывающему коду.
    2. Почему x в main не изменился после addTen(x)?
    Параметр передан по значению — изменилась копия.
    3. Зачем прототип?
    Чтобы компилятор знал функцию до её полного определения.
    4. Может ли void-функция содержать return без значения?
    Да, return; просто завершает функцию.
