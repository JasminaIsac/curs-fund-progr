    Ввод и вывод информации

    Научимся печатать на экран и читать данные с клавиатуры через stdio.h: printf и scanf.

    0 разделов 0 примеров C 0 вопросов
    1. Какой спецификатор у int в printf/scanf?
    %d
    2. Почему в scanf пишут &x?
    Нужен адрес переменной, чтобы функция записала туда введённое значение.
    3. Как вывести число x и перейти на новую строку?
    printf("%d\n", x);
