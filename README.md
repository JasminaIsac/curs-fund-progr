# FP.curs — Основы программирования (C)

Интерактивный курс по дисциплине **Основы программирования** — Молдавский государственный университет, кафедра информатики.

**Автор:** Isac Jasmina, ассистент университета  
**Язык материалов:** русский  
**Язык примеров:** C  
**Стиль:** оттенки зелёного и серого (Manrope + IBM Plex Mono)

## Как открыть

1. Откройте файл `index.html` в браузере.
2. Или локальный сервер:

```bash
python -m http.server 8080
```

Затем: http://127.0.0.1:8080/

## Как пользоваться

- Боковое меню (☰) — список всех тем курса.
- В каждой теме: разделы, интерактивные примеры C (симулированный вывод), вопросы для самопроверки.
- Скопируйте код из примера и проверьте в IDE или на [onlinegdb.com](https://www.onlinegdb.com/) (язык C).
